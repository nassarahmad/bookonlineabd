# 🎓 موقع حفل التخرج - عبدالرحمن اياد الظيراوي

موقع تخرج احترافي وفاخر بتصميم ذهبي وأسود، مع نظام إدارة للتعليقات.

---

## 📁 الملفات الرئيسية:

### 1. `index.html` - الصفحة الترحيبية
- صفحة البداية بتصميم كتاب فاخر
- صورة الخريج داخل الكتاب
- زر "أهلاً وسهلاً" للدخول إلى الموقع

### 2. `my-graduation.html` - صفحة التخرج الرئيسية
- صورة الخريج مع إطار ذهبي متوهج
- اقتباسات تحفيزية متحركة (تتغير كل 8 ثواني)
- معرض صور التخرج (4 صور)
- نموذج كتابة التهاني
- نظام إخفاء التعليقات عن الزوار
- مشغل موسيقى تلقائي

---

## 🔐 نظام الأدمن:

### كيفية تسجيل الدخول كأدمن:
1. افتح صفحة `my-graduation.html`
2. اضغط على: **Ctrl + Shift + A**
3. أدخل كلمة السر: **`admin2026`**
4. اضغط Enter أو زر "دخول"

### مميزات وضع الأدمن:
- ✅ رؤية **جميع** التعليقات والتهاني
- ✅ شارة ذهبية في الزاوية العلوية اليسرى تقول "👑 وضع الأدمن"
- ✅ الجلسة تبقى نشطة حتى إغلاق المتصفح

### الزوار العاديون:
- ✅ يمكنهم كتابة تهنئة جديدة
- ❌ **لا يمكنهم** رؤية تعليقات الآخرين
- 📝 يظهر لهم رسالة: "الرسائل مخفية للحفاظ على الخصوصية"

---

## 🎨 المميزات:

### التصميم:
- 🌟 خلفية سوداء مع نجوم ذهبية متحركة
- 💫 تأثيرات حركية احترافية
- 📱 تصميم متجاوب (يعمل على الموبايل)
- 🎨 ألوان ذهبية وسوداء فاخرة

### الاقتباسات التحفيزية:
- 8 اقتباسات ملهمة
- تتغير تلقائياً كل 8 ثواني
- تأثيرات انتقال سلسة

### معرض الصور:
- 4 صور للتخرج
- النقر على الصورة يفتحها بحجم كبير
- إغلاق بالضغط على ESC أو ×

### الموسيقى:
- تشغيل تلقائي عند فتح الموقع
- أغنية "ارفع راسك يا خريج - لؤي قواسمة"
- زر تحكم في الزاوية اليسرى السفلية

## 🚀 كيفية النشر:

### الطريقة 1: GitHub Pages (موصى بها)
1. أنشئ حساب على https://github.com
2. أنشئ مستودع جديد (Repository)
3. ارفع جميع الملفات
4. فعّل GitHub Pages من Settings → Pages
5. الرابط سيكون: `username.github.io/repository-name`

### الطريقة 2: Netlify
1. اذهب إلى https://www.netlify.com
2. اسحب مجلد المشروع وأفلته
3. ستحصل على رابط فوراً

### الطريقة 3: Vercel
1. اذهب إلى https://vercel.com
2. ارفع المشروع
3. ستحصل على رابط فوراً

## 🔧 التخصيص:

### تغيير كلمة سر الأدمن:
افتح `my-graduation.html` وابحث عن:
```javascript
const ADMIN_PASSWORD = 'admin2026';
```
غيّر `admin2026` إلى كلمة السر الجديدة.

### إضافة اقتباسات جديدة:
ابحث عن `motivationalQuotes` في `my-graduation.html` وأضف:
```javascript
{
    text: "الاقتباس الجديد",
    author: "اسم المؤلف"
}
```

### تغيير الموسيقى:
استبدل ملف MP3 بملف جديد، أو غيّر المسار في:
```html
<source src="اسم_الملف_الجديد.mp3" type="audio/mpeg">
```

## 📞 الدعم:

إذا واجهت أي مشكلة:
1. تأكد من رفع **جميع** الملفات (HTML + الصور + الموسيقى)
2. تأكد من أن أسماء الملفات صحيحة
3. جرب فتح الموقع في متصفح آخر
