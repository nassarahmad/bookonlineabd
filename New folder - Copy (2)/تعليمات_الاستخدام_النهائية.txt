🚀 الخطوة 1: تشغيل السيرفر (Backend)
═══════════════════════════════════════════════════════════

1. افتح Terminal/PowerShell
2. اذهب لمجلد backend:
   cd "C:\Users\Ahmad\Desktop\New folder - Copy (2)\backend"

3. شغّل السيرفر:
   node server.js

4. يجب أن تشوف:
   ✅ Server is running on port 5001
   📝 Environment: development
   🔗 Health check: http://localhost:5001/health
   MongoDB connected successfully

⚠️ ملاحظة: لا تقفل الـ Terminal! خليه مفتوح والسيرفر شغال

═══════════════════════════════════════════════════════════
🌐 الخطوة 2: فتح الموقع (Frontend)
═══════════════════════════════════════════════════════════

1. افتح ملف: index.html
2. اضغط عليه مرتين لفتحه في المتصفح
3. اضغط "أهلاً وسهلاً"
4. ستنتقل لصفحة التخرج (my-graduation.html)

═══════════════════════════════════════════════════════════
👤 كيف يستخدم المشروع كـ User (زائر)
═══════════════════════════════════════════════════════════

1. افتح الموقع (index.html)
2. اضغط "أهلاً وسهلاً"
3. انزل لقسم "اكتب لي ذكرى"
4. اكتب اسمك (اختياري)
5. اكتب رسالتك
6. اضغط "إرسال الرسالة"
7. ✅ ستظهر رسالة نجاح!

⚠️ ملاحظات مهمة:
• كل IP يمكنه إرسال رسالة واحدة فقط
• الرسالة تُحفظ في قاعدة البيانات (MongoDB)
• الرسائل لا تضيع عند عمل Refresh
• الزوار لا يرون الرسائل (مخفية للخصوصية)

═══════════════════════════════════════════════════════════
🔐 كيف يستخدم المشروع كـ Admin (مدير)
═══════════════════════════════════════════════════════════

1. افتح الموقع (my-graduation.html)
2. اضغط: Ctrl + Shift + A
3. ستظهر نافذة تسجيل الدخول
4. اكتب كلمة السر: terawi2003
5. اضغط "دخول"
6. ✅ تم تسجيل الدخول بنجاح!

الآن يمكنك:
• رؤية جميع الرسائل الحقيقية من المستخدمين
• رؤية أسماء المرسلين
• رؤية وقت إرسال كل رسالة
• الرسائل لا تضيع عند عمل Refresh
