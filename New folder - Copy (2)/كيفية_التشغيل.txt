الخطوة 1️⃣: تشغيل الـ Backend (السيرفر)
═══════════════════════════════════════════════════════════

1. افتح Terminal/PowerShell
2. اذهب لمجلد المشروع:
   cd "C:\Users\Ahmad\Desktop\New folder - Copy (2)"

3. ادخل مجلد backend:
   cd backend

4. شغّل السيرفر:
   node server.js

5. يجب أن تشوف:
   ✅ Server is running on port 5000
   📝 Environment: development
   🔗 Health check: http://localhost:5000/health
   MongoDB connected successfully

⚠️ ملاحظة: لا تقفل الـ Terminal! خليه مفتوح والسيرفر شغال

═══════════════════════════════════════════════════════════
الخطوة 2️⃣: تشغيل الـ Frontend (الموقع)
═══════════════════════════════════════════════════════════

اختر واحدة من الطرق التالية:

🔹 الطريقة 1: صفحة الاختبار (الأسهل)
   1. افتح ملف: test-api.html
   2. اضغط عليه مرتين لفتحه في المتصفح
   3. جاهز! 🎉

🔹 الطريقة 2: الموقع الأصلي
   1. افتح ملف: index.html
   2. اضغط عليه مرتين لفتحه في المتصفح
   (ملاحظة: هذا لا يزال يستخدم localStorage)

═══════════════════════════════════════════════════════════
👤 كيف تستخدم المشروع كـ User (زائر)
═══════════════════════════════════════════════════════════

في صفحة test-api.html:

1. اكتب اسمك (اختياري)
2. اكتب رسالتك
3. اضغط "إرسال رسالة"
4. ستظهر رسالة نجاح! 🎉

⚠️ ملاحظة: كل IP يمكنه إرسال رسالة واحدة فقط!

═══════════════════════════════════════════════════════════
🔐 كيف تستخدم المشروع كـ Admin (مدير)
═══════════════════════════════════════════════════════════

في صفحة test-api.html:

1. انزل لقسم "قسم الأدمن"
2. اكتب كلمة المرور: admin123
3. اضغط "تسجيل الدخول"
4. بعد تسجيل الدخول:
   - اضغط "تحميل الرسائل" لعرض جميع الرسائل
   - اضغط "حذف" لحذف أي رسالة
   - اضغط "تسجيل خروج" للخروج

═══════════════════════════════════════════════════════════
🧪 اختبار سريع
═══════════════════════════════════════════════════════════

1. تأكد أن السيرفر شغال (الخطوة 1)
2. افتح test-api.html في المتصفح
3. جرب إرسال رسالة كـ User
4. جرب تسجيل الدخول كـ Admin
5. شوف الرسائل واحذف واحدة
